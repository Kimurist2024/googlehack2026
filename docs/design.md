# 設計の考え方

ムシトリは、AIに任せる範囲を絞っています。正解、採点、声をかける順、説明を聞きたい行の選び方は、実行結果と記録から機械的に決めます。Gemini に任せるのは、問いの選定、解説、質問の言い回し、まとめ、振り返りの対話だけです。

## 1. 問いの作り方

提出コードを隔離環境で実行し、次の3つを記録します（[`apps/api/qgen/harness.py`](../apps/api/qgen/harness.py)）。

- 最後に表示された内容
- 変数への代入を1つずつ（行番号と値）
- 数値や比較演算子を1か所ずつ変えた版の、最後の表示

そこから3種類の問いを作ります（[`apps/api/qgen/questions.py`](../apps/api/qgen/questions.py)）。

| 種類 | 例 | 正解の出どころ |
|---|---|---|
| 出力の予測 | このプログラムが最後に表示する内容は何ですか | 実行したときの表示 |
| 変数の追跡 | 変数 `total` が取る値を順に並べたとき、3番目の値は何ですか | 代入の記録 |
| 変更の影響 | 4行目の `>` を `>=` に変えると、最後に表示される内容は何になりますか | 変えた版の表示 |

選択肢の誤答は、同じ実行記録の値から、正解と同じ種類（数か文字か）のものを選びます。3つそろわなければ自由入力にします。同じ行に同じ記号が2つあって問いの指す場所があいまいになるものは作りません。

## 2. 声をかける順

誤答の数と問いの種類の重みから、1人ずつの見込みを出し、小さい順に声をかけます（[`apps/api/app/ordering.py`](../apps/api/app/ordering.py)）。

```text
t = τ ÷ (p̃ × w)
p̃ = (1 + 誤答数) ÷ (2 + 問題数)   全問正解でも0にせず、順番の最後に残す
w = 誤答した問いの種類の重みの平均
τ = 1人にかかる時間。初期値は30秒で、教員の記録の所要時間の中央値で更新する
```

教員が持ち時間を入れると、その中で声をかけられる人数だけを「いま」の順番にします。処置を記録した生徒は、持ち時間の計算から外します。

## 3. 本人の説明を聞きたい行

締切のたびに、生徒ごとの記録（Firestore の `classes/{id}/students/{sid}`）に、課題ごとの正答数、使った書き方、説明を聞いた行、教員の記録を足します。そのうえで、次の根拠から行を選びます（[`apps/api/app/insight.py`](../apps/api/app/insight.py)）。

| 根拠 | 決め方 | 重み |
|---|---|---|
| 誤答した問いが指す行 | 採点結果と、問いが指す行（実行の記録から取る） | 2（1問増えるごとに+1） |
| 本人が初めて使った書き方 | 構文木から `for` 文、関数の定義、内包表記、`.append()` などを行ごとに取り出し、記録にあるこれまでの提出と比べる。最初の課題では判断しない | +1 |
| クラスでほとんど使われていない書き方 | 同じ課題の提出のうち、使った人が5人に1人以下（少なくとも1人）。3人未満のクラスでは判断しない | +1（前の根拠とそろうとさらに+1） |

- 1人につき最大3行。問いで確かめていない行は、初めての書き方で、しかもクラスで少ないときだけ、1行まで挙げます。
- 正解した問いが指す行は挙げません。本人が説明できたものとして扱います。
- 出力の予測の誤答は行を指せないので、「プログラム全体の流れ」として最後に置きます。
- 代入や `print` のように、どの生徒も使う書き方は数えません。

これは「AIを使った証拠」を探す仕組みではありません。書いた本人なら説明できるはずの箇所を、教員が短い時間で本人に聞けるようにするためのものです。

## 4. Gemini の出力の検査

Gemini の文は、使う前にすべて機械的に検査します（[`apps/api/qgen/ai.py`](../apps/api/qgen/ai.py)）。1つでも通らなければ、その回は既定の文（テンプレート）を使います。

- 文字数の上限を超えていない
- 「理解していない」「不正」「コピー」「自力で」など、生徒を評価したりAIの使用を疑ったりする言葉がない
- 質問案とまとめに「AI」という言葉そのものがない
- 存在しない行番号を書いていない。質問案はその行だけを指し、まとめは行番号を書かない（課題ごとにコードが違うため）
- 渡したコード、問い、記録にない数値を書いていない
- 質問の数が行の数と同じで、同じ質問が重なっていない

生徒のコードはコメントを取り除いてから Gemini に渡し、`<code>` などの囲みの中はデータであって指示ではないと明示します。
